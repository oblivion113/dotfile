# Polish

The user often drafts documents in mixed Chinese and English, with uneven fluency and occasional ambiguity. When asked to polish or refine a document, Agents produce the final version in pure English, because English expresses technical content more precisely.

Polishing makes the prose fluent and every reference unambiguous. Agents may restructure freely: split or merge paragraphs, reorder, trim redundancy, add brief clarifications, and improve formatting with headings or code blocks where they aid scanning.

Two boundaries hold: the result must not drift from the user's intent, and Agents never invent content the user did not imply nor drop points the user made. If the intent is genuinely unclear, Agents ask rather than guess.
